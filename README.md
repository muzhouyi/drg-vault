# 矿工档案库

《深岩银河》（Deep Rock Galactic）中文存档查看与编辑工具。支持查看及调整资源、进度、武器配装、核心、超频和涂装，并导出修改后的存档。

[下载最新版本](https://github.com/muzhouyi/drg-vault/releases/latest)

## 使用

下载发布页面中的 `DRG-save-editor-zh-v8.html`，双击在 Chrome 或 Edge 中打开。

首次使用时，按以下方法设置游戏目录：

1. 在 Steam 游戏库中右键《深岩银河》，选择 **管理 → 浏览本地文件**。
2. 在编辑器顶部点击 **设置游戏目录**，选择 Steam 刚刚打开的 **Deep Rock Galactic 文件夹本身**，不要选择其中的 `FSD` 或 `SaveGames` 文件夹。
3. 编辑器会在该目录下定位 `FSD\Saved\SaveGames` 并读取当前玩家存档。此后可使用 **读取游戏存档** 再次载入；自动载入可在页面右上角关闭。

也可以点击 **选择存档**，手动打开单个 `.sav` 文件。若浏览器不支持文件夹访问，仍可通过此方式编辑并导出新存档。单文件网页无需安装或启动其他程序。

## v8 相比 v7 的更新

- **游戏目录与自动载入：**可授权游戏安装目录并直接读取当前玩家存档；浏览器允许时会记住目录，重新打开页面可自动载入。浏览器撤销权限后可手动恢复。
- **备份与还原：**可创建和查看备份，查看职业等级与模块等摘要，并选择已有备份进行还原。备份保存在游戏目录的 `FSD\Saved\back` 下。
- **安全替换：**可在确认后将修改直接写入当前存档。写入前自动备份原文件；若源存档在编辑期间发生变化，将拒绝覆盖。
- **配装操作：**调整了配装图标、复制配装槽和武器解锁的展开方式。已购买模块单击切换装备，双击切换购买状态；取消购买时同步卸下相关配装中的模块。

替换或还原存档前请先退出游戏，并保留自己的备份。
